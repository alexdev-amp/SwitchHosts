# SwitchHosts (internal fork)

This is an internal fork of [SwitchHosts](https://github.com/oldj/SwitchHosts) — the hosts file manager by [oldj](https://github.com/oldj), still the best place to start if that's all you need: [switchhosts.app](https://switchhosts.app).

We extended it with one thing specific to our organization: a connected source that logs into our internal hosts API and syncs servers dynamically, instead of managing every entry by hand.

**If you're not part of our org**, this fork won't do anything useful for you — go use the [original project](https://github.com/oldj/SwitchHosts) instead.

**If you are part of our org**, grab the latest build from [Releases](../../releases).
